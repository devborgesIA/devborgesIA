# Julio Borges

**`AI Engineer`**

AI engineer building data and LLM systems for real operations. I started inside the operation, running process automation for companies, and today I design and build the architecture behind it: data pipelines, integrations and agent orchestration. My current system serves an internet service provider. Its data foundation runs in production with immutable history, atomic writes, a rehearsed backup restore and same-day failure alerts, in a codebase with 3,700+ automated tests. The agent layer comes next. I deliver through my own multi-agent pipeline (architect, TDD builder, blind auditor, deploy operator), with hooks that stop an unreviewed push or deploy. Based in Rio de Janeiro, Brazil, building through Typemind.
